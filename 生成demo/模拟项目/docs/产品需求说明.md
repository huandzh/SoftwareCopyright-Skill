# StudioAgent AI 视频制片平台 产品需求说明（模拟示例）

> 本文档属于演示用模拟素材，随模拟源码一起提供，仅用于演示软著资料生成流程。

## 1. 产品定位

面向短视频创作者、小型内容团队和品牌市场部门，把"写剧本、画分镜、出素材、配音、合成"
串成一条可追踪的流水线。创作者只需要用自然语言描述想法和修改意见，平台内的多个智能体
按阶段协作，产出可直接使用的成片。

## 2. 目标用户

- 独立视频创作者：没有固定团队，希望快速把创意变成可发布的短片。
- 内容工作室：同时推进多个项目，需要统一管理素材与成本。
- 品牌与市场团队：需要按季度批量产出产品宣传视频。

## 3. 核心使用场景

1. 创作者在项目列表新建项目，用一句话描述创意。
2. 剧本分析师拆解创意，给出题材、节奏和关键情节。
3. 分镜规划师把剧本拆成镜头列表，标注景别与时长。
4. 视觉素材生成师为每个镜头生成候选画面，创作者挑选或撤回。
5. 视频合成师把选中的画面合成为镜头片段。
6. 配音师与音效设计师补齐旁白、台词和环境音。
7. 创作者确认后导出成片，进入全局素材库复用。

## 4. 功能范围

- 账号：邮箱注册、登录、退出与预算设置。
- 项目：新建、重命名、按阶段筛选、归档、导出成片。
- 制片对话：自然语言指令、流式回复、随时中断生成。
- 智能体协作：六类角色状态展示与阶段性产出摘要。
- 项目资产：按角色、场景、道具、分镜、视频、配音、音效、成片八类查看。
- 候选素材：候选评分、采用、撤回与重新生成。
- 全局素材库：跨项目搜索、复用与删除素材。
- 计费：按语言模型、图片、视频、语音、音效和存储分项统计，超出预算时暂停生成。

## 5. 非功能要求

- 生成任务不得阻塞网页操作，长耗时步骤走异步任务。
- 素材下载地址必须带签名与过期时间，避免被外部直接抓取。
- 单个项目失败不能影响其它项目，失败原因要能看到并能重试。
- 成本必须对创作者透明，完成阶段前给出预计剩余成本。
